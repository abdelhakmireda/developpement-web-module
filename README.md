
# 🧭 **README – Module 1 : Introduction au Développement Web (HTML & CSS)**

## 🎯 **Présentation du module**

Bienvenue dans le **Module 1 : Développement Web – HTML & CSS**.
Ce module est **le point de départ** du parcours complet de développement web que nous allons construire ensemble.

Il est conçu **à la fois pour les débutants** et pour les personnes **souhaitant rafraîchir leurs connaissances**.
Même si nous commençons par les bases, notre objectif est d’aller **progressivement vers des compétences avancées** :

> HTML → CSS → JavaScript → Programmation orientée objet (OOP) → Backend → APIs

---

## 🌍 **Objectifs pédagogiques**

À la fin de ce module, tu seras capable de :

* Comprendre **le fonctionnement du Web** (client, serveur, navigateur).
* Créer une **page web structurée avec HTML**.
* Styliser et mettre en page ton site avec **CSS**.
* Publier ton travail sur **GitHub**.

Tu auras également une base solide pour aborder :

* **JavaScript** (dynamiser les pages),
* **OOP** (structurer ton code),
* **Langage backend** (Node.js, PHP, ou autre),
* **API REST** (communication entre serveurs et clients).

> “Apprendre le web, c’est comprendre la logique qui relie le code et le monde réel.”

Chaque étape du module est pensée pour être :

* **Interactive** (beaucoup de pratique),
* **Accessible** (même sans expérience),
* **Progressive** (chaque notion sert la suivante),
* **Réutilisable** (chaque fichier peut être intégré dans un vrai projet).
